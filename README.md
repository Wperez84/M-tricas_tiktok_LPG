# Métricas TikTok LPG

Página de retorno OAuth y política de privacidad para la app de TikTok for Developers (Grupo LPG).

## Archivos
- `Metricas.gs` — script de Google Apps Script (credenciales vacías: llénalas en CONFIG o en Script Properties; nunca las subas al repositorio).
- `callback.html` — Redirect URI del OAuth de TikTok.
- `privacy-policy.html` — política de privacidad.
